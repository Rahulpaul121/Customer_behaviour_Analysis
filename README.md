# 📊 Customer Behavior Analysis

End-to-end customer behavior analysis using PostgreSQL, Python (Jupyter Notebook), and Power BI to generate actionable business insights.

# 🧠 Project Overview

This project focuses on understanding customer behavior and purchasing patterns through structured data analysis and visualization.
Data was queried and analyzed using PostgreSQL, explored and validated in Jupyter Notebook, and finally visualized using Power BI dashboards to communicate insights in a business-friendly format.

# 🎯 Project Goals

- Understand customer demographics and buying behavior

- Identify high-value and repeat customers

- Analyze revenue and transaction trends

- Present insights using interactive dashboards

| Category      | Tools                       |
| ------------- | --------------------------- |
| Database      | PostgreSQL                  |
| Analysis      | SQL, Python (Pandas, NumPy) |
| Visualization | Power BI                    |
| Environment   | Jupyter Notebook            |


# 🔍 Methodology
1️⃣ SQL Analysis (PostgreSQL)

- Used joins, aggregations, subqueries, and window functions

- Analyzed purchase frequency, customer contribution, and revenue trends

2️⃣ Exploratory Data Analysis (Jupyter Notebook)

- Validated SQL outputs using Python

- Performed summary statistics and data quality checks

3️⃣ Data Visualization (Power BI)

- Built interactive dashboards with KPIs and filters

- Visualized customer segments and performance trends

# 📊 Key Insights

- A small segment of customers contributes a major share of revenue

- Clear patterns in repeat purchases and customer engagement

- Identified opportunities for customer retention and growth
